# 📖 Overview

This repository contains my complete MongoDB Bootcamp covering MongoDB fundamentals, CRUD operations, Query Operators, Aggregation Framework, Indexing, Transactions, and Advanced PyMongo.

The goal of this repository is to learn MongoDB professionally through hands-on coding using Python and PyMongo.

# ▶️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Create Virtual Environment

```bash
python -m venv .venv
```

Activate

Windows

```bash
.venv\Scripts\activate
```

Install packages

```bash
pip install -r requirements.txt
```
